## Body

## Problem

Cargo.lock contains sha256 checksums for every registry crate. The download path receives a checksum field but it is unclear whether the downloaded tarball is verified against it. If crates.io or its CDN is compromised, unverified code enters the build.

## Fix

- After downloading a .crate tarball, compute sha256 and compare to the Cargo.lock checksum
- Fail hard on mismatch — no fallback, no retry with different checksum
- This is not optional. Cargo does this. We must too.
