## Summary

Set up continuous integration on macOS using a self-hosted Mac Studio runner.

## Why self-hosted

- FSKit requires macOS 26+ (not available on GitHub-hosted runners)
- Need to test VFS mount/unmount, FSKit extension loading
- Need to test seatbelt sandbox profiles
- Faster builds on Apple Silicon than x86 GitHub runners

## Scope

### Runner setup

- GitHub Actions self-hosted runner on Mac Studio
- Runner labels: `self-hosted`, `macos`, `apple-silicon`
- Secure the runner (dedicated user, limited permissions, cleanup between jobs)

### CI jobs

- `cargo check --workspace` — compilation
- `cargo nextest run` — tests
- `cargo clippy --all-targets` — lints
- Swift build for VixenFSExtension (xcodebuild or swift build)
- Integration test: mount VFS, read files, unmount
