## Body

## Problem

The main branch does not compile on macOS or Windows. This is a hard blocker for any macOS or Windows development work.

## Details

The codebase has platform-specific code (`vx-vfs/src/macos.rs`, `vx-vfs/src/linux.rs`, vendored `fuse3` crate is Linux-only) but the build has not been kept green on non-Linux platforms.

## Fix

- Identify and fix all compilation errors on macOS
- Identify and fix all compilation errors on Windows (at minimum: `vx`, `vxd`, `vx-store` — the core non-VFS crates)
- Gate platform-specific crates behind `cfg` so the workspace compiles everywhere
- This must be fixed before macOS/Windows CI (#181, #182) can be set up

## Acceptance criteria

- `cargo check --workspace` passes on macOS (aarch64-apple-darwin)
- `cargo check --workspace` passes on Windows (x86_64-pc-windows-msvc), or at minimum a subset of crates that makes sense
