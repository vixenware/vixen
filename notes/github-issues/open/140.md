## Body

## Problem

The manifest parser rejects crates with more than one [[bin]] target. CrateType only has Lib and Bin — no staticlib, cdylib, or rlib variants.

## Scope

- Support multiple [[bin]] targets in a single crate
- Support crate-type = ["cdylib"], ["staticlib"], ["rlib"] in [lib]
- Each output type may need different rustc flags
- Relevant for: FFI libraries, WASM targets, plugin systems
