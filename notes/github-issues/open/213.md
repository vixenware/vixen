## Body

## Summary

Implement feature resolution so that `--cfg feature="X"` flags are passed to rustc for each activated feature. This is the core mechanism that makes real-world crates.io dependencies compile correctly.

## Parent issue

Part of #114 (resolve and fetch transitive crates.io dependencies).

## Current state

- `[features]` sections are rejected at parse time in `vx-manifest` (lines 309-316)
- Dependency `features = [...]` are already parsed and stored in `PathDependency.features` and `VersionDependency.features` but never used
- No `--cfg` flags are passed to rustc in `service_vfs.rs`
- The `RustCompileRequest` has no field for activated features/cfg flags

## Scope

- Parse `[features]` tables from registry crate Cargo.toml (requires #212 first)
- Resolve `default` features: when a dependency is included without `default-features = false`, activate its `default` feature and everything it implies
- Handle `features = ["foo", "bar"]` in dependency declarations — activate those features on the dep
- Handle `default-features = false` — suppress default feature activation
- Transitive feature propagation: if feature `A` enables feature `B` which enables feature `C`, all three are active
- Add activated features to `CrateNode` (or a parallel data structure)
- Add `--cfg feature="X"` flags to the `RustCompileRequest` / rustc invocation
- Feature values in `[features]` that are just strings (e.g., `std = []`, `alloc = ["dep:alloc_impl"]`) — handle the simple cases

Does NOT include:
- `dep:foo` syntax and optional dependencies (tracked separately)
- `cfg()` predicate evaluation for target-gated deps (tracked separately)
- Workspace-wide feature unification (#153)

## Key design decisions

- Features are resolved per-crate during graph construction, not at compile time
- The resolved feature set is part of the cache key (different features = different compilation)
- Feature resolution happens in `crate_graph.rs` after `finalize_with_registry`

## Milestone test

A project depending on `serde = { version = "1", default-features = false, features = ["alloc"] }` (no derive, no std) gets `--cfg feature="alloc"` passed to rustc when compiling serde.
