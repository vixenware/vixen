## Body

## Problem

If vxd crashes mid-build (OOM, signal, power loss), the CAS may contain partial state — a manifest written but its blobs missing, or a cache key pointing to an incomplete result.

## Scope

- `vx doctor`: verify CAS integrity (every manifest has all its blobs, every cache key points to valid data)
- On startup, detect and clean up incomplete writes from the previous session
- Report what was found and fixed
