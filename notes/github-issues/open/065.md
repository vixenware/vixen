# Issue #65: Investigate DMG-backed mount flow for macOS 15 compatibility (defer until customer demand)

- State: `OPEN`
- URL: https://github.com/bearcove/vixen/issues/65
- Created: `2026-02-06T21:53:42Z`
- Updated: `2026-02-09T21:28:44Z`
- Labels: P3, area/vfs, platform/macos

## Body

Context
- Current VixenFS integration requires macOS 26 because we rely on URL-based file system resources.
- macOS 15 cannot use this flow as implemented.

Proposal
- Add a compatibility path based on DMG-backed mounts instead of URL file system resources.

Important prioritization
- Do **not** schedule this by default.
- Only start implementation if/when a customer explicitly requests macOS 15 support.

Acceptance criteria (when activated)
- Vixen can mount and function on macOS 15 using the alternative mount path.
- Existing macOS 26+ URL-based path remains supported.
- Setup UX clearly indicates which path is active and why.
