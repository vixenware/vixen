## Body

## Problem

`--remap-path-prefix` is used to ensure cache hits across checkout paths, but there is no test that verifies two builds of the same code from different directories produce the same CAS blob hash.

## Fix

Test that:
1. Build crate X from /tmp/a/
2. Build crate X from /tmp/b/
3. Assert output blob hashes are identical

This verifies the path remapping, timestamp elimination, and any other sources of non-determinism are handled.
