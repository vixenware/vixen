## Body

Cache key computation in `crates/vxd/src/queries.rs` has the same hashing pattern repeated across 6 functions:

- `cache_key_compile_bin`
- `cache_key_compile_rlib`
- `cache_key_compile_rlib_with_deps`
- `cache_key_compile_bin_with_deps`
- `cache_key_cc_compile`
- `cache_key_cc_link`

Each one manually calls `hasher.update()` for version prefix, session_id, toolchain, target, profile, etc. When a new field needs to be added to all cache keys (like `session_id` was), every function has to be updated individually.

Consider a builder or helper that handles the common prefix (version, session, toolchain, target, profile) and lets each function append its specific fields.
