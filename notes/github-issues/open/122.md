## Summary

Let rust-analyzer use vx as its flycheck provider, so on-save diagnostics come from vixen's build system instead of cargo check.

## How it works

rust-analyzer's flycheck runs a command on save and parses its output for diagnostics. Currently it supports cargo and custom commands.

## Scope

- Implement a `vx check` command that outputs cargo-compatible JSON diagnostics
- Or use rust-analyzer's custom flycheck with vx's native diagnostic format
- Fast path: if nothing changed, return cached diagnostics
- Integrate with vx's incremental build (only recheck affected crates)

## Depends on

- M5 (Structured Diagnostics) for machine-readable output
- M6 (rust-project.json) for rust-analyzer to load the project at all
