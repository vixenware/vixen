## Body

## Problem

The CAS grows without bound. Old toolchain versions, superseded compilation outputs, and stale source ingestions accumulate forever. There is no way to reclaim space.

## Scope

- `vx gc`: mark-and-sweep from live cache keys to referenced blobs
- Delete unreferenced blobs and manifests
- Report: space reclaimed, entries removed
- Safe: only delete entries not referenced by any current cache key
- Optional: age-based eviction (delete entries not accessed in N days)
