## Summary

Adopt modern terminal escape sequences to make vx output richer in terminals that support them.

## Features

### 1. OSC 8: Clickable hyperlinks

Make file paths in diagnostics clickable. When rustc reports an error at \`src/main.rs:42:10\`, emit:

\`\`\`
ESC ] 8 ; ; file:///path/to/src/main.rs:42:10 ST src/main.rs:42:10 ESC ] 8 ; ; ST
\`\`\`

Clicking opens the file in the user's editor. Also useful for:
- Links to build reports (\`vx explain --web\` URLs)
- Links to GitHub issues in diagnostics

**Supported by**: Ghostty, kitty, WezTerm, Windows Terminal, iTerm2, most modern terminals.

### 2. OSC 9/777: Desktop notifications

Notify when a build finishes while the terminal is in the background:

\`\`\`
ESC ] 9 ; Build succeeded (42 actions, 12.3s) BEL
\`\`\`

Or on failure:

\`\`\`
ESC ] 9 ; Build FAILED: 2 errors in vx-vfs BEL
\`\`\`

This should be **configurable** — not everyone wants notifications. Default off or respect a config flag.

### 3. Kitty Graphics Protocol: inline build graph

At the end of a build, if the terminal supports the kitty graphics protocol, render a small swimlane/timeline visualization inline in the terminal. Shows action parallelism, critical path, cache hits.

**Supported by**: kitty, Ghostty, WezTerm.

Detection: query the terminal for graphics support before attempting to render. Fall back to text summary if unsupported.

This would be a fun complement to the full web-based graph explorer (#126) — a quick visual right in your terminal.

## Detection

- Check \`$TERM_PROGRAM\` and \`$TERM_FEATURES\` for known support
- Or just emit the sequences — unsupported terminals ignore unknown OSC sequences
- For kitty graphics: use the detection query (send a test image, check response)
