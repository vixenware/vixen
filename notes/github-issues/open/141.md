## Body

## Problem

Every cold build requires network access to download toolchains and registry crates. No offline mode exists.

## Scope

- `vx fetch`: pre-populate the CAS with all toolchains and crates needed for a build
- `vx build --offline`: refuse to make network requests, fail if anything is missing from CAS
- Enables air-gapped environments, reproducible CI, airplane coding
- Foundation: the CAS already stores everything, just need a pre-fetch command and a network gate
