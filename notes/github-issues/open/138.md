## Body

## Problem

No linker configuration. Rustc uses the system default, which is often slow (GNU ld on Linux). lld and mold can cut link times by 5-10x on large projects.

## Scope

- Configuration for linker selection (per-target)
- Pass -C linker=... or -C link-arg=-fuse-ld=... to rustc
- Include linker choice in cache key (different linkers can produce different output)
- Make linker available inside sandbox
- Default: auto-detect fastest available linker
