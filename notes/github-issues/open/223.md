## Summary

Create planner performance benchmarks for EDN rule planning and fixed-point expansion.

We need repeatable benchmarks for:

- static graph planning
- dynamic graph growth via dyndeps/dynout
- no-op incremental planning

## Scope

- benchmark scenarios (100/500/2000+ nodes)
- workload fixtures with controlled dynamic behavior
- metrics collection (latency, iteration count, nodes/edges emitted, dedup rates)
- regression threshold policy

## Acceptance Criteria

- Benchmark suite is runnable in CI and locally
- Reports include percentile latency and planner iteration stats
- Baselines are captured and tracked over time
- Threshold breaches fail CI with links to benchmark artifacts
