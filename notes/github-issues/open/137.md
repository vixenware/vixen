## Body

## Problem

The current code uses the same triple for host and target. Cross-compilation requires:

- Acquiring rust-std component for the target triple (separate from host toolchain)
- Passing --target to rustc
- Potentially a target-specific linker
- Proc macros and build scripts always compile for host, even when cross-compiling

## Scope

- Separate host triple from target triple throughout the pipeline
- Download target-specific rust-std component
- Pass --target to compilation actions
- Build scripts and proc macros use host triple
- Cache keys must include target triple

## Key targets

- aarch64-unknown-linux-gnu (ARM Linux servers)
- wasm32-unknown-unknown (WebAssembly)
- x86_64-apple-darwin ↔ aarch64-apple-darwin (Apple cross)
