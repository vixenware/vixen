## Body

## Problem

`vx clean --home` requires interactive confirmation but provides no flag to bypass it. This makes it unusable in scripts and CI:

```
vx kill && vx clean --home --yes
Error: unknown flag: --yes
```

## Fix

Add `--force` or `--yes` flag that skips the confirmation prompt. This is a standard CLI pattern for destructive operations.

`vx clean --home --yes` should work without prompting.
