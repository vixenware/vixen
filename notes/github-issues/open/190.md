# Issue #190: vx clean --home should imply vx kill

## Body

## Problem

`vx clean --home` needs the daemon stopped to clean up, but doesn't do it itself. Users have to remember to run `vx kill && vx clean --home`, and if they forget, the clean either fails or leaves stale state.

## Fix

`vx clean --home` should automatically kill the daemon before cleaning. The daemon manages state in `~/.vx/` — you can't clean that directory while it's running.

No need for a separate `vx kill` step. If the daemon isn't running, the kill is a no-op.
