## Body

## Problem

The Edition enum supports all four editions and flows into rustc flags, but there are no tests that actually compile edition-specific syntax. An edition regression would silently produce broken builds.

## Scope

- Test fixtures with edition-specific code:
  - 2015: no dyn keyword required
  - 2018: async/await, dyn Trait required
  - 2021: disjoint capture in closures, IntoIterator for arrays
  - 2024: gen keyword, new lifetime elision rules
- Compile each fixture with its edition, assert success
- Compile 2024 code with edition=2021, assert failure (proves edition flag matters)
