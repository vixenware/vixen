## Summary

Generate rust-project.json from vixen's crate graph so rust-analyzer provides IDE features without Cargo.

## What rust-project.json contains

- Crate roots, editions, dependencies (as indices into the crate array)
- Activated cfgs and features
- env!() values (OUT_DIR, etc.)
- Sysroot location
- Proc macro dylib paths
- Source include/exclude patterns

## Scope

- After crate graph resolution, serialize to rust-project.json
- Place at workspace root (or configure via rust-analyzer.linkedProjects)
- Include all workspace crates + their dependency crates
- Handle proc macro dylib paths (requires M4)
- Handle OUT_DIR for crates with build scripts (requires M3)
- Regenerate on crate graph changes

## Stretch: discoverConfig

rust-analyzer supports a discoverConfig command that outputs project descriptions on-the-fly. Instead of writing a file, vx could be that command. This is the Buck2/Bazel pattern.
