## Body

## Problem

The executor treats each CompileRustCrate as atomic. Cargo pipelines metadata emission so downstream crates can start compiling as soon as upstream metadata (not the full rlib) is available. Without pipelining, deep dependency chains serialize compilation.

## How Cargo does it

rustc can emit metadata (.rmeta) before finishing codegen. Downstream crates only need .rmeta to begin their own compilation. The full .rlib is only needed at link time.

## Scope

- Use --emit=metadata to get .rmeta early
- Split action graph: metadata action (fast) → codegen action (slow)
- Downstream depends on metadata action, not codegen action
- This can significantly improve parallelism for deep dependency trees
