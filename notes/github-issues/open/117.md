## Summary

Support the common pattern where build.rs uses the cc crate to compile C/C++ source files.

## Context

The cc crate is one of the most depended-on crates in the ecosystem. It invokes a C compiler from build.rs. This requires:
- The C compiler (cc/gcc/clang/zig) accessible inside the sandbox
- System include paths available
- Object files written to OUT_DIR
- Link flags emitted via cargo:rustc-link-lib

## Scope

- Make zig cc (or system cc) available inside build script sandbox
- Provide system headers (sysroot) in VFS
- Test with the cc crate compiling real C code
- Handle cargo:rustc-link-lib=static=foo and cargo:rustc-link-search=native=...
