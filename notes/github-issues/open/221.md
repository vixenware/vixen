## Summary

Implement lowering from `RulePlan` into the existing `ActionGraph`/executor pipeline.

This lets us adopt rule-based planning without rewriting execution in one step.

## Scope

- Mapping from `RulePlan` nodes to existing `Action` variants
- Mapping typed edges into executor dependency structure + report metadata
- Preservation of provenance for explain/report outputs
- Feature-gated integration in build flow

## Acceptance Criteria

- RulePlan-generated Rust project can execute through existing executor path
- Build report preserves rule provenance and edge kinds
- Lowering failures produce explicit diagnostics (missing mapping, invalid edge, etc.)
- Feature flag allows side-by-side fallback to legacy planner

## Notes

This is the bridge that de-risks migration.
