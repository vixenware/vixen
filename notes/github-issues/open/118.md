## Summary

Compile proc-macro crates to host-target dylibs and pass them to rustc.

## Current state

Proc macro crates are detected and rejected with an error.

## Scope

- Compile proc-macro crates with --crate-type=proc-macro (produces .so/.dylib)
- Always compile for host target (proc macros run at compile time)
- Pass to dependent crate compilation via --extern name=path/to/libname.dylib
- Handle proc macros from crates.io
- Handle proc macros that depend on other crates (syn, quote, proc-macro2)

## Milestone test

A project depending on serde + serde_derive compiles successfully.
