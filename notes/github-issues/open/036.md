# Issue #36: Eliminate syn from dependency tree

- State: `OPEN`
- URL: https://github.com/bearcove/vixen/issues/36
- Created: `2025-12-24T13:27:08Z`
- Updated: `2026-02-09T21:28:55Z`
- Labels: P2, area/build-graph

## Body

## Goal

Remove `syn` entirely from the dependency tree to improve compile times. `syn` is a heavy proc-macro dependency (~15-20s to compile) and removing it can shave 30-60s off clean builds.

## Current Syn Sources

From `cargo tree -i syn`:

| Proc-Macro | Brought By | Fix |
|------------|-----------|-----|
| `async-stream-impl` | rapace-core | Replace with manual async stream |
| `enum_dispatch` | rapace-core | Replace with manual match dispatch |
| `futures-macro` | futures-util (via futures-timeout) | Use tokio::time::timeout instead |
| `miette-derive` | facet-reflect[miette] | Make derive optional in facet |
| `pin-project-internal` | pin-project (via futures-timeout) | Removed when futures-timeout goes |
| `test-log-macros` | vx (dev-dep) | Write simple test helper |
| `thiserror-impl` | clonetree | Clonetree being removed (VFS route) |
| `tokio-macros` | tokio[full] | Use tokio without macros feature |
| `tracing-attributes` | tracing | Use tracing without attributes feature |

## Phase 1: Vixen-Local Changes

### 1.1 Remove `tokio-macros`

**Current** (`Cargo.toml`):
```toml
tokio = { version = "1", features = ["full"] }
```

**Fix:** Replace with explicit features:
```toml
tokio = { version = "1", features = ["rt-multi-thread", "io-util", "net", "time", "fs", "process", "sync", "signal"] }
```

**Code changes:**
- `crates/vx/src/main.rs`
- `crates/vx-aether/src/main.rs`
- `crates/vx-rhea/src/main.rs`
- `crates/vx-cass/src/main.rs`
- `crates/vx-aether/src/tests.rs`
- `crates/vx-cass/examples/test_client.rs`

Replace `#[tokio::main]` with:
```rust
fn main() -> eyre::Result<()> {
    let rt = tokio::runtime::Builder::new_multi_thread()
        .enable_all()
        .build()?;
    rt.block_on(async_main())
}

async fn async_main() -> eyre::Result<()> {
    // original main body
}
```

Replace `#[tokio::test]` with:
```rust
#[test]
fn test_name() {
    let rt = tokio::runtime::Builder::new_current_thread()
        .enable_all()
        .build()
        .unwrap();
    rt.block_on(async {
        // test body
    });
}
```

### 1.2 Remove `test-log`

**Current** (`crates/vx/Cargo.toml`):
```toml
[dev-dependencies]
test-log = { version = "0.2", features = ["trace"] }
```

**Fix:** Remove dependency and add helper:
```rust
fn init_test_tracing() {
    use tracing_subscriber::EnvFilter;
    let _ = tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .try_init();
}
```

Tests call `init_test_tracing();` at the start.

### 1.3 Tracing attributes

No `#[instrument]` usage found in vixen. The dependency comes from upstream crates.

## Phase 2: Rapace Changes (bearcove/rapace)

### 2.1 Remove `async-stream`

**Location:** `rapace-core/Cargo.toml`, used in `rapace-macros/src/lib.rs`

Replace `try_stream!` with manual `Stream` implementation or `futures::stream::unfold`.

### 2.2 Remove `enum_dispatch`

**Location:** `rapace-core/src/transport.rs`

Replace with manual match:
```rust
impl Transport {
    pub async fn send_frame(&self, frame: Frame) -> Result<(), TransportError> {
        match self {
            Transport::Mem(t) => t.send_frame(frame).await,
            Transport::Stream(t) => t.send_frame(frame).await,
            Transport::Shm(t) => t.send_frame(frame).await,
            Transport::WebSocket(t) => t.send_frame(frame).await,
        }
    }
    // ... other methods
}
```

### 2.3 Remove `futures-timeout`

**Location:** `rapace-core/src/session.rs`

Replace:
```rust
use futures_timeout::TimeoutExt;
rx.timeout(duration).await
```

With:
```rust
use tokio::time::timeout;
timeout(duration, rx).await
```

**Note:** If WASM support is needed, use conditional compilation:
```rust
#[cfg(target_arch = "wasm32")]
// use gloo_timers
#[cfg(not(target_arch = "wasm32"))]
// use tokio::time::timeout
```
