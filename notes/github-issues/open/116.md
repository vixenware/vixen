## Body

## Summary

Enable build.rs execution for both workspace crates and registry crates.

## Current state

Infrastructure exists in vx-rs/build_script.rs (env vars, cargo: directive parsing) but is not wired into the build. Registry crates with build scripts are rejected.

## Scope

- Compile build.rs as a binary (host target)
- Execute inside sandbox with correct env vars:
  - OUT_DIR, CARGO_MANIFEST_DIR, TARGET, HOST, RUSTC, etc.
  - DEP_* env vars from dependency link attributes
- Parse cargo: directives from stdout:
  - cargo:rustc-cfg, cargo:rustc-env, cargo:rustc-link-lib, cargo:rustc-link-search
  - cargo:rerun-if-changed (for incrementality)
  - cargo:warning (pass through to user)
- Feed outputs into dependent crate compilation
- Handle build script dependencies (build-dependencies in Cargo.toml)

## Sandbox interaction

Build scripts run inside the sandbox like any other action. They get VFS access to their source tree and OUT_DIR but nothing else.
