## Body

## Problem

ActionGraph::from_crate_graph produces the DAG that determines build parallelism and ordering. This is only tested implicitly via full builds. If a dependency edge is dropped, a crate compiles before its dep is ready → crash or wrong output.

## Fix

Given a Cargo.toml with N dependencies, snapshot the action graph (nodes + edges). Use insta for snapshot testing. Any change to graph construction shows up as a diff in review.
