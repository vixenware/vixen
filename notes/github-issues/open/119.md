## Body

## Summary

Switch from capturing raw stderr to using rustc's structured JSON diagnostic output.

## Current state

vx-runner captures stdout/stderr as raw strings and passes them through. No parsing, no formatting control.

## Scope

- Add --error-format=json --json=diagnostic-rendered-ansi,artifacts to rustc invocations
- Parse JSON diagnostics into an internal representation
- Preserve: message, level, spans (file/line/col), code, children, suggestions
- Preserve suggestion_applicability (MachineApplicable, MaybeIncorrect, etc.)
- Render diagnostics with rich terminal formatting (colors, underlines, margin annotations)
- Handle artifact notifications (for tracking produced files)

## Why

- Control over formatting (consistent across all compilers)
- Machine-applicable suggestions can be offered to the user
- Foundation for IDE integration (diagnostics as data, not text)
- Can filter, deduplicate, summarize across many compilation units
