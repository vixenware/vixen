## Body

## Problem

When running `vx build`, there's no way to see what's actually happening step by step. The VXD daemon does a lot of work internally that is never communicated back to the `vx` CLI, so the user has no visibility into the build process.

## Desired behavior

`vx build --verbose` (or similar) should show a detailed log of everything that happened and why:

- Triplet inference ("inferred target triple: x86_64-unknown-linux-gnu")
- Rust version determination ("determined Rust version: stable")
- Toolchain acquisition ("acquiring toolchain rust-1.82.0... cached" or "downloading...")
- Build decisions ("building crate foo, hash: abc123...")
- Cache hit/miss ("foo: cache hit" vs "foo: rebuilding because dependency bar changed")
- Rebuild reasons, similar to how cargo explains why it's recompiling something

This requires plumbing information from VXD back through to the CLI so it can be displayed.
