## Summary

Build a dual-planner parity harness that compares legacy hardcoded planning vs EDN rule planning.

The harness should detect drift in:

- graph node identity/kind
- edge topology and edge kinds
- dynamic expansion behavior
- cache key-relevant inputs

## Scope

- Fixture corpus for representative Rust workspaces
- Normalized graph diff tool
- CI integration and failure triage output

## Acceptance Criteria

- Dual-planner mode produces machine-readable diff reports
- CI job gates on parity for covered fixture set
- Diff output includes provenance and actionable mismatch classification
- Initial fixture set covers path deps, registry deps, build scripts, proc macros

## Notes

Parity harness is mandatory before switching defaults.
