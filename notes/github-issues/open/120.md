## Summary

Capture structured diagnostics from C/C++ compilers, not just raw stderr.

## Options

| Compiler | Flag | Format | Since |
|----------|------|--------|-------|
| Clang | -fdiagnostics-format=sarif-stderr | SARIF 2.1.0 | LLVM 16 |
| Clang | -serialize-diagnostics <file> | Binary (Clang-specific) | Old |
| GCC | -fdiagnostics-format=sarif-stderr | SARIF 2.1.0 | GCC 13 |
| GCC | -fdiagnostics-format=json | GCC JSON (deprecated) | GCC 9-15 |

## Recommendation

Use SARIF where available (Clang 16+, GCC 13+). Fall back to raw stderr for older compilers. Don't try to parse unstructured compiler output.

## Scope

- Add SARIF flags to zig cc / clang / gcc invocations when available
- Parse SARIF JSON into the same internal diagnostic representation as rustc
- Unified rendering: same rich terminal output regardless of source compiler
