Durable home for multi-thread architectural work on Vixen. Flat namespace: every page sits at the wiki root, page type carried in frontmatter. Cross-references are wiki-style: `[[Page title]]`.

## Page types

| Type             | Purpose                                              |
| ---------------- | ---------------------------------------------------- |
| `Vision`         | Long-form aspirational direction.                    |
| `Milestone`      | Concrete goal with enumerated success criteria.      |
| `Decision`       | ADR-style record of an architectural choice.         |
| `Question`       | Open architectural question.                         |
| `Experiment`     | Hypothesis + result.                                 |
| `ArchitectureNote` | How something works *today*.                       |
| `Glossary`       | One term, two or three sentences.                    |

## Authorship discipline

Agents write scaffolding (this README, schemas, templates, validators) and faithfully transcribe stated vision when asked. Substance — visions, decisions, milestone narratives — is human-authored.
