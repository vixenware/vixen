## Canonical project notes

Repository-local product and implementation documentation belongs in this repository. Cross-repository Vixenware architecture, infrastructure, build, and operational notes live in `~/w/vixenware/vixen-central`; start with `infra/notes/direction.md`, `infra/notes/build.md`, and `kb/README.md`.

If work required guessing or asking for project information, update the canonical note after resolving it. Merge or restructure existing notes rather than adding another isolated account.
