# Vixen Brand

## Core

- Primary color: `#E88602`
- Logo source: `art/fox.svg`

## Supporting Palette

- Ember: `#EB6D3B`
- Sand: `#EEDC9A`
- Ink: `#252525`
- Soft surface: `#FCFBFA`

## Usage

- Use `#E88602` for primary calls-to-action, highlights, and active states.
- Keep body text in high-contrast neutrals (`#252525` / system text colors).
- Prefer soft surfaces and subtle shadows over high-contrast borders.
